# bigdog

A lightweight front-end project built with HTML, CSS, and JavaScript.

## Overview

This repository contains a static web project whose composition is primarily CSS, with supporting JavaScript interactivity and HTML structure. The current language breakdown is approximately:

- CSS: 42%
- JavaScript: 35.4%
- HTML: 22.6%

## Project Purpose

This project is intended to serve as a simple web-based application or landing page. It is designed to be easy to open locally and extend as needed.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kelvinperrie/bigdog.git
   ```
2. Navigate into the project folder:
   ```bash
   cd bigdog
   ```
3. Open the main HTML file in a browser, or run a local static server:
   ```bash
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000` in your browser.

## Repository Structure

Typical front-end structure may include:

- `index.html` — page structure
- `styles.css` or a `css/` folder — styling
- `script.js` or a `js/` folder — interactive behavior

## Notes

This repository is intentionally simple and easy to customize. If you are building on top of it, you can add pages, assets, or additional JavaScript modules as the project grows.
